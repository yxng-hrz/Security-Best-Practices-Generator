Identity & Access Management

Owner: Cloud Platform / IAM · ISO 27001 A.5.15, A.5.18, A.8.2, A.8.5 | CIS v8 5, 6 | NIST CSF PR
IDPriorityControl
CLD-IAM-01P1Enforce phishing-resistant MFA for every console user, and always for root / global administrator accounts.
CLD-IAM-02P1Lock down root and break-glass accounts: no access keys, hardware MFA, sealed credentials and alerting on any use.
CLD-IAM-03P2Apply least privilege with role-based access; forbid wildcard actions and resources on production roles.
CLD-IAM-04P2Replace long-lived access keys with workload identities and short-lived federated credentials.
CLD-IAM-05P3Review cloud roles and permissions quarterly and remove unused permissions and identities.

Network & Exposure

Owner: Cloud Platform / Network · ISO 27001 A.8.20, A.8.22 | CIS v8 4, 12, 13 | NIST CSF PR
IDPriorityControl
CLD-NET-01P1Never expose management ports (SSH, RDP, database ports) directly to the internet; use a bastion or zero-trust access.
CLD-NET-02P1Block public access to object storage at organization level; allow exceptions only through documented approval.
CLD-NET-03P2Segment workloads in dedicated VPCs/VNets with default-deny security groups and explicit flows.
CLD-NET-04P2Use private endpoints for managed services (databases, storage, key vaults) instead of public endpoints.
CLD-NET-05P3Protect internet-facing applications with a WAF and DDoS protection service.

Logging & Threat Detection

Owner: SOC / Cloud Security · ISO 27001 A.8.15, A.8.16, A.5.23 | CIS v8 8, 13 | NIST CSF DE
IDPriorityControl
CLD-LOG-01P1Enable control-plane audit logging in every account, subscription and region, stored immutably.
CLD-LOG-02P1Centralize security logs in a dedicated, access-restricted security account or workspace.
CLD-LOG-03P2Enable the provider's native threat-detection services and route findings to the SOC / SIEM.
CLD-LOG-04P2Alert on high-risk events: root usage, policy changes, disabled logging, new public exposure.
CLD-LOG-05P3Define log retention aligned with regulatory and forensic requirements (e.g. NIS2, DORA).

Data Protection & Resilience

Owner: Cloud Platform / Data owners · ISO 27001 A.8.24, A.8.13, A.5.30 | CIS v8 3, 11 | NIST CSF PR, RC
IDPriorityControl
CLD-DAT-01P1Encrypt sensitive data at rest and enforce TLS 1.2+ for all data in transit.
CLD-DAT-02P1Keep backups of critical workloads in a separate account with immutability (object lock / vault lock).
CLD-DAT-03P2Use customer-managed keys with rotation and separation of duties for regulated data.
CLD-DAT-04P2Test restoration and regional failover of critical services against documented RTO/RPO.
CLD-DAT-05P3Tag resources with data classification so that controls can be applied by sensitivity.
